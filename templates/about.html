About This Project

📘 Project Title

Explainable Student Performance Prediction Using Machine Learning

🎯 Tagline

"See the prediction. Know the reason."

🧠 How It Works

  • Collects student data: knowledge test, study hours, previous marks, assignments
  • Uses Machine Learning (Random Forest) to predict pass/fail
  • SHAP explains which factors influenced the prediction
  • Provides personalized recommendations for improvement
  • Enables What-If analysis for interactive exploration

🛠️ Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python, Flask
  • ML: Scikit-learn, Random Forest, XGBoost
  • Explainability: SHAP
  • Database: SQLite
